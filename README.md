# Dila Qonita Hidayati, Portfolio

Personal portfolio built with Vite, vanilla JavaScript, GSAP (ScrollTrigger, SplitText, Flip, Draggable, MotionPath, DrawSVG), Lenis, and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/data/`: content (projects, certificates, experience, logos)
- `src/motion/`: animation per section
- `src/styles/main.css`: styles
- `public/`: images, certificates, logo, CV
